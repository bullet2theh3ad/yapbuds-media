# yapbuds-media

Public images and videos for YapBuds social posts, served by GitHub Pages so Buffer can fetch them
(Buffer has no upload endpoint). Only media Steve has approved goes here. Managed from
`bullet2theh3ad/yapbuds-marketing` by the `yb-media-host` agent.

Layout: `<series or week>/<post id>.<png|mp4>`, for example `tiktok/tiktok-01.mp4`.
Public URL: `https://bullet2theh3ad.github.io/yapbuds-media/<path>`.
